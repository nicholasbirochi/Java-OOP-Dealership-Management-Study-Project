# Estudo de POO — Concessionária em Java

Exercício de programação orientada a objetos que representa diferentes veículos de uma concessionária. O código inclui classes para carro, moto, caminhão, barco e helicóptero, além da classe base `Veiculos`.

## Código

O projeto está em `JavaApplication2/`, com as classes em `JavaApplication2/src/Concessionaria/`. O arquivo `Concessionaria.java` contém o ponto de entrada.

## Como abrir

Abra a pasta `JavaApplication2` como projeto Java no NetBeans, escolha um JDK compatível com as propriedades do projeto e execute a classe principal. O repositório inclui `build.xml` e a configuração original do NetBeans.

O objetivo é acompanhar a organização das classes e os conceitos de POO. Não é um sistema de vendas pronto para uso.
